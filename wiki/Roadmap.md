# 🗺️ Roadmap

Geplante Features und Entwicklungsrichtungen für GateCore.

---

## 🎯 Aktuelle Ziele (v1.1)

### 🐳 Docker-Erweiterungen
- [ ] Container-Ressourcen (CPU/RAM-Limits) konfigurierbar
- [ ] Docker-Image-Verwaltung (pull, push, tag, löschen)
- [ ] Docker-Netzwerke verwalten
- [ ] Container-Statistiken (CPU/MEM) live anzeigen

### 🖥️ Hypervisor-Erweiterungen
- [ ] VM-Snapshots erstellen & wiederherstellen
- [ ] LXC-Snapshots
- [ ] VM-Konsole (VNC/noVNC) direkt im Browser
- [ ] Live-Migration von VMs
- [ ] Netzwerk-Bridge-Konfiguration

### 📊 Monitoring
- [ ] Alerting & Benachrichtigungen (E-Mail, Webhooks)
- [ ] Benutzerdefinierte Dashboards
- [ ] Längerer Metrik-Verlauf (7 Tage / 30 Tage)
- [ ] Temperatur-/Lüfterüberwachung

### 🔒 Sicherheit
- [ ] Zwei-Faktor-Authentifizierung (2FA/TOTP)
- [ ] Rate-Limiting für Login
- [ ] HTTPS-Zertifikate (Let's Encrypt)
- [ ] Audit-Log für alle Aktionen

---

## 🌐 Langfristige Vision (v2.x)

- [ ] **REST-API-Dokumentation** (OpenAPI/Swagger)
- [ ] **Kubernetes-Support** (Clustermanagement über K8s)
- [ ] **Benachrichtigungs-Dienste** (Telegram, Slack, Discord)
- [ ] **Template-Marketplace** (Community-Templates)
- [ ] **Backup & Restore** für VMs, Container & Storage
- [ ] **Multi-Site-Cluster** mit automatischem Failover
- [ ] **Mobile App** (iOS & Android)
- [ ] **SSO** (Single Sign-On via OIDC/SAML)
